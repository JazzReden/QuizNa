# Essay criteria and Ella practice grading

New essay questions support a criteria editor with unique names, point budgets, and descriptions, plus a five-level rubric table (Excellent 100%, Proficient 75%, Developing 50%, Beginning 25%, No evidence 0%). Scores follow the displayed percentages consistently. The frontend and backend require the sum of criterion points to equal the essay's maximum. Legacy free-text guides remain valid.

Criteria are stored as human-readable text in the existing rubric field and are included in published quiz snapshots. Editing a draft rubric does not alter an existing attempt's criteria. The grading page uses the attempt's frozen questions. Older essays without structured criteria offer a suggested Accuracy/Completeness/Clarity guide; it does not rewrite their published questions. Teachers can select performance levels to calculate a score, or enter a manual score. Criterion breakdowns and feedback persist in the existing teacher_feedback field and are visible to students only under the existing score-release rules. Reopening a grade restores its selected performance levels. Entering a manual score clears the draft breakdown so it cannot silently contradict the entered score. The editor and grader load on demand.
